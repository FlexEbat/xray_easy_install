## Внимание! Тестовая ветка

Эта ветка **только для тестирования**. Использование этой версии **совершенно не гарантирует работоспособность**. С очень большой вероятностью у вас **всё сломается** и **ничего не заработает**.

Используете на свой страх и риск. Если вы надеетесь на стабильность — **уйдите прямо сейчас**.
