TODO: Создание XHTTP + Reality за CDN(CF)
Чтобы реализовать **VLESS + xhttp + TLS** через Cloudflare (CDN) с минимальным участием пользователя, нужно настроить связку: **Cloudflare → Nginx (порт 443/2053) → Unix Socket → Xray**.
Вот пошаговый план для другого ИИ, чтобы он корректно модифицировал твой скрипт:

1. Подготовка Inbound в Xray
Нужно добавить в конфиг Xray (`config.json`) новый входящий поток, который будет слушать не сетевой порт, а **Unix-сокет**. Это безопаснее и быстрее для проксирования через Nginx.
1.1 **Protocol:** `vless`.
1.2 **Listen:** `/dev/shm/xray.sock` (размещение в оперативной памяти для скорости).
1.3 **StreamSettings:** * `network`: `xhttp`.
    1.3.1 `xhttpSettings`: `path` (секретный путь), `mode`: `packet-up` (лучшая совместимость с CDN).
2. Настройка Nginx (Реверс-прокси)
Nginx должен выступать «лицом» сервера, принимать зашифрованный трафик от Cloudflare и передавать его в сокет Xray.
2.1 **Порт:** Использовать `443` или `2053` (оба поддерживаются Cloudflare в режиме Proxy).
2.2 **Конфигурация Location:** Создать блок `location` для секретного пути (например, `/secret-xhttp`).
2.3 **Параметры прокси:**
    2.3.1 `proxy_pass` на `http://unix:/dev/shm/xray.sock`.
    2.3.2 Обязательная передача заголовков: `Host`, `X-Real-IP`, `X-Forwarded-For`.
    2.3.3 Поддержка HTTP/1.1 и апгрейд соединения (`Upgrade`, `Connection`).
3. Автоматизация в Bash-скрипте
Для «минимального количества нажатий» ИИ должен изменить следующие функции в `xray_easy.sh`:

3.1 **Функция `generate_xray_config`:**
    3.1.1 Добавить логику проверки: если `HAS_DOMAIN=true`, в массив `inbounds` дописывается конфиг с сокетом.
3.2 **Функция `install_core`:**
    3.2.1 При настройке Nginx автоматически добавлять блок проксирования для `xhttp`.
     3.2.2 Убедиться, что права на сокет позволяют Nginx (`www-data`) писать в него.
3.3 **Функция `generate_user_pages`:**
    3.3.1 Добавить генерацию **третьей ссылки** специально для CDN.
    3.3.2 Формат ссылки: `vless://UUID@DOMAIN:2053?type=xhttp&security=tls&sni=DOMAIN&path=PATH&host=DOMAIN#Name-CDN`.

4 Настройки на стороне Cloudflare (Инструкция для юзера)
Скрипт должен в конце выводить краткую памятку:
4.1 Включить **Proxy** (оранжевое облако) для домена.
4.2 В разделе **SSL/TLS** поставить режим **Full** или **Full (Strict)**.
4.3 Убедиться, что в разделе **Network** включены WebSockets и gRPC (на всякий случай для стабильности `xhttp`).
